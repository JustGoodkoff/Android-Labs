# Android Labs

**Технологии:** Kotlin, Android SDK, AndroidX, XML, ConstraintLayout, RecyclerView, Fragments, Material Components, Gradle Kotlin DSL.

Репозиторий содержит четыре учебных Android-приложения:

| Проект | Описание |
| --- | --- |
| `lab2-1` | Приложение из трёх `Activity` с отдельными XML-разметками. Переходы выполняются по кругу с помощью явных `Intent`, а возврат с третьего экрана на первый очищает лишние экраны из стека через `FLAG_ACTIVITY_CLEAR_TOP`. |
| `lab2-2` | Три экрана на основе `Fragment`, размещённые внутри одной `Activity` через `FragmentContainerView`. Переключение реализовано транзакциями `FragmentManager`; переходы добавляются в back stack, который сбрасывается при возврате с третьего экрана на первый. |
| `lab4` | Форма для проверки введённого значения. Если пользователь вводит неверный код, поле плавно смещается влево и вправо с помощью `ObjectAnimator`, создавая трёхсекундную shake-анимацию ошибки. |
| `labRView` | Экран музыкального списка на `RecyclerView` и `LinearLayoutManager`. Данные песни вынесены в отдельную модель, отображение реализовано через собственные `Adapter` и `ViewHolder`, а элемент списка содержит иконку, название, исполнителя и кнопку воспроизведения. |
